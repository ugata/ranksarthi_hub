# Rank Sarthi

Rank Sarthi is a preparation-intelligence platform for JEE, NEET, and NDA aspirants.

## Development

You need Node.js and Bun to run the project locally.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
bun run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
